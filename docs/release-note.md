## 2.0.0

- 新增文件夹导入功能，可将常用文件夹添加到启动台
- 新增图标名称字号设置
- 快捷键设置新增一键清空按钮

- 优化应用与分组整理，修复跨页拖拽、加入分组失败无提示、右键菜单中文件夹顺序错乱等问题
- 优化编辑与弹窗交互，修复名称可为空、图标预览尺寸异常、弹窗打开时仍会触发全局操作等问题
- 修复关闭应用后仍保留编辑状态，以及编辑弹窗意外隐藏桌面的问题
- 修复删除分组内元素时弹窗无法正常关闭的问题
- 分组节点不再支持直接删除
- 修复自动更新不可用、下载进度显示异常的问题
- 修复鼠标滚轮滚动过快时连续翻页的问题
